# CLI 命令参考

## 通用说明

- CLI 模式下在 `mini-ai>` 提示符后输入
- 输入 `/` 自动弹出命令补全菜单，方向键选择，Tab 确认
- `/model` 和 `/skill` 等命令支持二级补全（提示参数选项）

---

## 命令列表

### 会话管理

| 命令 | 说明 |
|------|------|
| `/save <名称>` | 保存当前对话为命名会话（跳过 system 消息） |
| `/load <名称>` | 加载已保存会话，恢复上下文 |
| `/sessions` | 列出所有已保存会话（标记当前） |
| `/clear` | 清空当前会话上下文（历史保留在 DB 中） |
| `/purge` | 彻底删除所有历史消息（不可恢复，需二次确认） |
| `/history` | 查看当前工作空间的历史消息列表 |

### 模型

| 命令 | 说明 |
|------|------|
| `/model` | 列出所有可用模型和当前模型 |
| `/model <名称>` | 切换模型，立即生效并持久化到 config.yaml |

### 技能

| 命令 | 说明 |
|------|------|
| `/skill` | 列出所有可用技能 |
| `/skill <名称>` | 加载并使用指定技能 |
| `/genskill <名称>` | 从当前对话总结生成技能，自动调用 install_skill 安装 |

### 工作空间

| 命令 | 说明 |
|------|------|
| `/workspace` | 列出所有工作空间 |
| `/workspace new <名称> [路径]` | 创建新工作空间（路径可选） |
| `/workspace add <路径>` | 添加现有目录为工作空间 |
| `/workspace remove <名称>` | 移除工作空间（数据备份到 `.名称.removed`） |
| `/workspace delete <名称>` | 删除工作空间（含所有数据） |
| `/workspace <名称>` | 切换到指定工作空间，自动重建 system prompt 和历史 |

### 思维链显示

| 命令 | 说明 |
|------|------|
| `/thinking` | 查看当前思维链显示模式 |
| `/thinking collapsed` | 折叠模式（默认）：仅显示 `💭 已思考 N 字 (Xs)`，`/thinking` 展开 |
| `/thinking expanded` | 展开模式：实时输出思考内容 |
| `/thinking hidden` | 隐藏模式：不显示，`/thinking` 仍可查看 |

### 对话模式

| 命令 | 说明 |
|------|------|
| `/plan` | 进入计划模式 📋 — 只输出分析和步骤规划，不调用工具 |
| `/act` | 切换到执行模式 ⚡ — Agent 可自由调用工具 |
| `/todos` | 显示当前任务计划列表 |

### 压缩与维护

| 命令 | 说明 |
|------|------|
| `/compact` | 手动触发对话压缩，摘要写入 `compaction_summary.md` |
| `/mcp` | 查看 MCP 服务器连接状态和工具列表 |

### 工具

| 命令 | 说明 |
|------|------|
| `/export [路径] [--thinking] [--tools]` | 导出对话为 Markdown，可选含思考过程和工具调用 |
| `/exit` / `/quit` / `q` | 退出 mini-ai |
